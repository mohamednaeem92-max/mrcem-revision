## Pages 1941–1942

Page 1941 displays question 3: “Oculomotor (CN III) palsy with sparing of the pupillary reflex is most likely caused by which of the following:” Options: Aneurysm of the posterior communicating artery; Brainstem metastases; Diabetes mellitus; Cavernous sinus disease; Subdural haematoma. Displayed key: Diabetes mellitus. Explanation: “Compressive causes of CN III palsy cause early pupillary dilatation because the parasympathetic fibres run peripherally in the nerve and are easily compressed.
