# Source Hierarchy and Non-Hallucination Rules

This audit uses the current MRCEM Primary scope as its curriculum frame. RCEM states that MRCEM Primary is a 180-question, three-hour single-best-answer paper mapped to the Basic Sciences Curriculum (June 2010), and that the current syllabus remains in use for the October 2026 sitting. The updated syllabus becomes the official reference from April 2027.[1][2]

## Evidence hierarchy

| Rank | Evidence | Permitted use |
|---|---|---|
| 1 | Original user-supplied PDF page or retained source image, tied to the question ID and source page | Establishes the original stem, option order, marked answer, and source wording. |
| 2 | Primary or official authority relevant to the topic, such as RCEM, NICE, BNF, UKHSA, WHO, CDC, MHRA, a medicine summary of product characteristics, or Cochrane | Verifies a factual answer and supports a concise high-yield statement. |
| 3 | Peer-reviewed review article or stable academic reference, such as NCBI Bookshelf | Used only when rank 2 does not cover a basic-science fact. |
| 4 | Educational summaries, commercial question banks, blogs, search snippets, and uncorroborated model output | Discovery only. Never sufficient evidence for a correction. |

## Non-hallucination rules

1. A change to option text, option ordering, or answer key requires agreement between the retained source page and at least one rank 1 to 3 external source. If the source page is unavailable, the record remains uncorrected and is added to the manual-review ledger.
2. Every new high-yield note or mnemonic requires a source-linked factual statement. A mnemonic may simplify a fact but cannot add a claim, threshold, exception, or recommendation absent from its cited source.
3. OCR drafts never become approved merely because an external source appears to support one option. The original source page must first confirm that the stem and choices were transcribed accurately.
4. Ambiguous questions, image-dependent questions, conflicting authorities, outdated guidance, and records with corrupt option text are retained as unresolved rather than guessed.
5. The audit preserves the raw OCR record, the proposed change, evidence URLs, retrieval date, reviewer status, and reason for any rejection.

## Scope note

The current bank contains 4 source-reviewed pilot records and 4,450 OCR drafts. The OCR drafts retain source links, but their client bundle does not contain the original page images. Therefore, any source-page comparison must retrieve the specific Drive PDF page or use a retained review bundle before a correction can be applied.
