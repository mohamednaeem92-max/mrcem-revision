## Record-by-record findings and guarded disposition

### Page 1283, source question 180

The source displays five options and marks **“The striated lower oesophageal sphincter muscle”** as key. The OCR draft has a leading artefact (`ww`) and retains only four percentage-free/percentage-bearing options in a malformed form. S1/S8 support the underlying correction: the lower oesophageal sphincter is a smooth-muscle high-pressure zone, not a distinct striated skeletal-muscle sphincter. The source wording is retained literally, with only OCR noise and percentage artifacts removed. **Disposition: guarded restoration.**

### Page 1284, source question 1

S4 identifies iliohypogastric origin/course but does not alter the source key; standard pelvic neuroanatomy supports pudendal motor supply to the external urethral sphincter. The source option order is restored exactly, including coccygeal nerve, iliohypogastric nerve, and iliohypogastric spelling. **Disposition: guarded restoration.**

### Page 1286, source question 3

The source displays five options and marks **L1** as key. The OCR draft contains an unusable option fragment and no marked key. S4 states that the iliohypogastric nerve is formed from the ventral primary rami of T12–L1, while common examination descriptions often simplify this to L1. The displayed source key is therefore retained, but the learning aid should record the anatomical variation rather than present L1 as universally exclusive. **Disposition: guarded restoration with a T12–L1 variation caveat.**

### Page 1288, source question 5

The source displays five options and marks **pelvic splanchnic nerves** as key. S3 states that pelvic splanchnic nerves carry visceral afferents and provide parasympathetic supply to the rectum and other hindgut/pelvic organs. It also distinguishes sympathetic sacral/lumbar pathways. Because rectal visceral afferent pathways can vary by level and pain type, the restored explanation must preserve the source answer while stating that this is the intended hindgut visceral-afferent answer, not an assertion that every rectal pain fibre travels exclusively by one route. **Disposition: guarded restoration with a scope caveat.**

### Page 1289, source question 6

The source displays five options and marks **spleen** as key. S2 explicitly describes the spleen as the most frequently injured visceral organ in blunt abdominal trauma. The source explanation also says liver and spleen are the most commonly injured organs, so the single-best-answer key is supported because liver is not an option. The stem’s handlebar mechanism is retained without adding a claim that the spleen is always injured in every upper-abdominal handlebar impact. **Disposition: guarded restoration with option-set caveat.**

## Limitations

The external sources corroborate the anatomy and the displayed keys but do not license rewriting the PDF into a different question. Where anatomy is level-dependent, variable, or option-set dependent, the mutation should add a concise caveat rather than silently generalize. The original PDF remains the authority for source wording and displayed answer keys.
