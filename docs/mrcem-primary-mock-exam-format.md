# MRCEM Primary Mock-Exam Format

## Official format verified 21 August 2026

The MRCEM Primary is a **single, three-hour theory paper** comprising **180 multiple-choice questions with single best answers (SBAs)**. RCEM maps the examination to the RCEM Basic Sciences Curriculum and the RCEM Curriculum. Correct responses score one mark, incorrect responses score zero, and there is no negative marking.[1][2]

## Application in Meridian Revision

The local mock workspace will use only approved, source-reviewed questions. It will not present unreviewed OCR draft items as exam-standard questions. The full Primary target is 180 SBA items in 180 minutes. While the approved bank contains fewer than 180 suitable questions, the app will create a clearly labelled partial mock from all available approved items, rather than repeat questions or simulate a full official paper.

The app will track answers locally, allow flagging and navigation during the session, lock the exam on submission or expiry, and show the raw score with no speculative pass/fail prediction because RCEM uses Angoff standard setting.[2]

## Live verification

The initial approved bank contains four source-reviewed questions. The live mock workflow therefore created a **four-question, four-minute partial mock**, randomised the order, excluded OCR drafts, displayed no answers or learning aids during the sitting, and exposed local flagging and paper-map navigation.

One answer and one review flag were recorded before submission. The completed summary correctly displayed the raw score (1/4), answered count (1/4), flagged count (1), and no pass/fail prediction.
