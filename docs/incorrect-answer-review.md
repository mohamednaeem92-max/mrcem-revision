# Incorrect-Answer Review

## Eligibility

A question enters the focused incorrect-answer review set when it is an approved local question with at least one recorded attempt and fewer correct answers than attempts. OCR drafts remain outside this workflow.

## Review behaviour

The Review queue shows the current count, provides a **Practice incorrect** action, and launches a dedicated session with the standard answer-first flow, explicit correct-answer explanation, learning aids, bookmarks, and local progress updates.
